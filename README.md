# TFM-UNIR
En este repositorio se encuentra los notebooks desarrollados para el Trabajo Fin de Máster centrado en el análisis de sentimientos aplicados a reseñas de películas. 

El notebbok imd.ipynb es el correspondiente al análisis principal del conjunto de datos IMDb, el cual está disponible públicamente en Kaggle emplenado el siguiente enlace: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews?resource=download.

El notebook tomatoes.ipynb es el correpondiente al análisis de validación del conjunto de datos de Rotten Tomatoes, el cual se carga directamente desde la librería datasets de Hugging Face.

Por úlitmo, la ejecuación de ambos notebooks se realiza ejecutando las celdas en orden y no se necesitan la descarga de archivos adicionales.
